## SYNOPSIS

Reboots a CloudPC

## SYNTAX

```powershell
Invoke-CPCReboot [-Name] <String> [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

The function will reboot a CloudPC

## EXAMPLES

### EXAMPLE 1

```powershell
Invoke-CPCReboot -Name "CloudPC01"
```
