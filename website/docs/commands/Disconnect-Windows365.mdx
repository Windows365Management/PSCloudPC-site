Disconnects from Windows 365 and clears the token cache.

## SYNTAX

```powershell
Disconnect-Windows365 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Disconnects from Windows 365 and clears the token cache.
